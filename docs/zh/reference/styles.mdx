# 样式

`styles` 提供了覆盖日历中任何 CSS 类的能力。您可以用 CSS 类列表替换任何值。

## 模块化 CSS

现有的 `styles/index.css`、`styles/layout.css` 和 `styles/themes/*.css` 仍提供完整样式并保持兼容。要减小 CSS 体积，可以只导入需要的部分。注册 JavaScript 扩展不会自动加载 CSS。

每组都提供 `core`、`motion`、`time`、`annotations`、`weeks` 和 `months`。请导入 `core` 和所有使用的扩展样式，包括以后通过 `set()` 启用的功能。

| 路径 | 内容 |
| --- | --- |
| `styles/index.css` | 全部布局及亮色/暗色主题 |
| `styles/{part}.css` | 所选部分的布局及亮色/暗色主题 |
| `styles/layout/{part}.css` | 仅所选部分的布局，不包含主题 |
| `styles/themes/{theme}/{part}.css` | 仅指定主题中所选部分的样式 |

带时间选择并自动切换亮色/暗色主题的日历：

```ts
import { Calendar, time } from 'vanilla-calendar-pro';
import 'vanilla-calendar-pro/styles/core.css';
import 'vanilla-calendar-pro/styles/time.css';

new Calendar('#calendar', {
  extensions: [time],
  selectionTimeMode: 24,
}).init();
```

要独立选择主题，请导入布局部分和对应的主题部分。例如，带时间选择的亮色日历：

```ts
import { Calendar, time } from 'vanilla-calendar-pro';
import 'vanilla-calendar-pro/styles/layout/core.css';
import 'vanilla-calendar-pro/styles/layout/time.css';
import 'vanilla-calendar-pro/styles/themes/light/core.css';
import 'vanilla-calendar-pro/styles/themes/light/time.css';

new Calendar('#calendar', {
  extensions: [time],
  selectionTimeMode: 24,
  selectedTheme: 'light',
}).init();
```

可以将 `light` 替换为 `dark` 或 `slate-light`。自定义主题只需导入对应的布局部分并添加自己的 CSS。主题检测和 `selectedTheme` 的行为不变；请加载日历可能切换到的所有主题。

每一层请选择完整文件或模块文件，避免重复加载相同规则。CSS 类名、选择器、浏览器支持以及公开的 `--vc-*` 自定义变量保持不变。某些主题部分（如 `motion` 和 `months`）没有主题专属规则，因此是有效的空 CSS 文件。

如果使用所有扩展，请保留完整样式表；它比同时导入全部六个部分的压缩效果更好。

下载的 `package.zip` 包含五个完整样式表。模块化 CSS 可通过 npm 包或直接 CDN 链接获取。

## CSS 变量

内置主题（`light`、`dark`、`slate-light`）中的每一种颜色都通过 CSS 自定义属性定义，并以主题的原始颜色作为回退值（fallback）。这意味着您只需设置少量变量即可重新设置日历样式，而无需修改任何 CSS 类，也不必担心主题覆盖是否能正确生效。

```css
:root {
  --vc-date-selected-bg: #7c3aed;
  --vc-date-selected-color: #fff;
}
```

如果变量未设置，日历的渲染效果与之前完全一致——只有当您显式设置某个变量时，效果才会改变。

<Info>在 `:root` 上设置变量会同时应用到所有主题（light/dark/slate-light 都读取相同的变量名）。若只想重新设置某一个主题的样式，请将覆盖限定在该主题的选择器范围内，例如：`[data-vc-theme='dark'] { --vc-date-selected-bg: #7c3aed; }`。</Info>

## 尺寸

日历几乎完全使用 `rem` 作为单位，因此会随根字体大小（root font-size）缩放。如果页面将其从浏览器默认的 `16px` 重置为其他值（常见于 Bootstrap 3 等较旧的框架，通常是 `10px`），日历会以错误的比例渲染。用一个 `transform` 即可恢复预期大小：

```css
[data-vc='calendar'] {
  transform: scale(16 / <根字体大小，单位 px>);
}
```

例如，根字体大小为 `10px` 时：`transform: scale(1.6);`。
