# 弹出窗口和工具提示

从没有扩展机制的版本升级时，请保留现有选项和回调。使用 ESM 时，添加 `annotations` 的具名导入，并在构造函数中配置 `extensions: [annotations]`。无需调用扩展函数。仅导入或注册扩展不会自动启用功能。

```ts
import { Calendar, annotations } from 'vanilla-calendar-pro';

new Calendar('#calendar', {
  extensions: [annotations],
  popups: { '2026-09-21': { html: 'Event' } },
}).init();
```

`popups`（包括仅含修饰符的条目）和 `onCreateDateRangeTooltip` 需要 `annotations`。通过 `inputMode` 打开的日历仍属于核心功能。

## 弹出窗口

日历允许您为任何日期添加带有信息的弹出窗口，这些信息将在悬停该日期时显示。

在提供的示例中，使用 CSS 修饰符突出显示特定日期，并将信息添加到弹出窗口。

有关弹出窗口的更多详细信息，请参阅参考指南。

## 工具提示

当 `selectionDatesMode` 参数设置为 `'multiple-ranged'` 时，可以使用工具提示。使用 `onCreateDateRangeTooltip`，您可以创建完全自定义的工具提示。
