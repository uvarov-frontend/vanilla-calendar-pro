# 弹出窗口和工具提示

从没有扩展机制的版本升级时，请保留现有选项和回调。使用 ESM 时，添加 `datePopups` 的具名导入，并在构造函数中配置 `extensions: [datePopups]`。无需调用扩展函数。仅导入或注册扩展不会自动启用功能。

```ts
import { Calendar, datePopups } from 'vanilla-calendar-pro';

new Calendar('#calendar', {
  extensions: [datePopups],
  popups: { '2026-09-21': { html: 'Event' } },
}).init();
```

此要求适用于 `popups` 选项，包括仅含 `modifier` 的条目。`inputMode` 打开的日历和范围提示（`onCreateDateRangeTooltip`）不需要此扩展。

## 弹出窗口

日历允许您为任何日期添加带有信息的弹出窗口，这些信息将在悬停该日期时显示。

在提供的示例中，使用 CSS 修饰符突出显示特定日期，并将信息添加到弹出窗口。

有关弹出窗口的更多详细信息，请参阅参考指南。

## 工具提示

当 `selectionDatesMode` 参数设置为 `'multiple-ranged'` 时，可以使用工具提示。使用 `onCreateDateRangeTooltip`，您可以创建完全自定义的工具提示。
