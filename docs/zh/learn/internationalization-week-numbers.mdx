# 周数

ESM 迁移：保留现有选项和回调，从 `vanilla-calendar-pro` 导入 `weeks`，并加入构造函数的 `extensions: [weeks]` 数组，无需调用扩展函数。

在某些国家/地区，使用周数来表示日期。
您可以通过将 `enableWeekNumbers` 参数设置为 `true` 来启用日历中周数的显示。
