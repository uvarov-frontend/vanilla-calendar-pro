# 选择和更改时间

从没有扩展机制的版本升级时，请保留现有选项和回调。使用 ESM 时，添加 `timePicker` 的具名导入，并在构造函数中配置 `extensions: [timePicker]`。无需调用扩展函数。仅导入或注册扩展不会自动启用功能。

```ts
import { Calendar, timePicker } from 'vanilla-calendar-pro';

new Calendar('#calendar', {
  extensions: [timePicker],
  selectionTimeMode: 24,
}).init();
```

通过激活 `selectionTimeMode` 参数，您将能够自动接收每次时间更改所需的必要数据。
