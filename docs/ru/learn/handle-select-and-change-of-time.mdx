# Выбор и изменение времени

При обновлении с версии без расширений сохраните прежние опции и обработчики. Для ESM добавьте именованный импорт и зарегистрируйте `timePicker` в конструкторе: `extensions: [timePicker]`. Вызывать расширение как функцию не нужно. Импорт или регистрация сами по себе не включают функцию.

```ts
import { Calendar, timePicker } from 'vanilla-calendar-pro';

new Calendar('#calendar', {
  extensions: [timePicker],
  selectionTimeMode: 24,
}).init();
```

Путем активации параметра `selectionTimeMode`, вы получаете возможность автоматически получать необходимые данные при каждом изменении времени.
