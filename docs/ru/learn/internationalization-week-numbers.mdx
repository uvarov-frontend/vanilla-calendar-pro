# Номера недель

Миграция ESM: сохраните существующие опции и обработчики, импортируйте `weeks` из `vanilla-calendar-pro` и добавьте его в массив `extensions: [weeks]` конструктора без вызова как функции.

В некоторых странах используют номера недель для обозначения дат.
Вы можете включить отображение номеров недель в календаре, установив параметр `enableWeekNumbers` в `true`.
