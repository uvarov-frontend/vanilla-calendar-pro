# Попапы и тултипы

При обновлении с версии без расширений сохраните прежние опции и обработчики. Для ESM добавьте именованный импорт и зарегистрируйте `datePopups` в конструкторе: `extensions: [datePopups]`. Вызывать расширение как функцию не нужно. Импорт или регистрация сами по себе не включают функцию.

```ts
import { Calendar, datePopups } from 'vanilla-calendar-pro';

new Calendar('#calendar', {
  extensions: [datePopups],
  popups: { '2026-09-21': { html: 'Event' } },
}).init();
```

Требование относится к опции `popups`, включая записи только с `modifier`. Для календаря, открываемого через `inputMode`, и тултипа диапазона (`onCreateDateRangeTooltip`) это расширение не требуется.

## Попапы

Календарь позволяет добавлять поп-апы с информацией для любого дня, которые будут отображаться при наведении на этот день.

В приведенном примере выделен определенный день с использованием CSS-модификатора, и добавлена информация в поп-ап.

## Тултипы

Тултипы можно использовать, когда для параметра `selectionDatesMode` установлено значение `'multiple-ranged'`. Используя `onCreateDateRangeTooltip`, вы можете создать полностью кастомизированный тултип.
