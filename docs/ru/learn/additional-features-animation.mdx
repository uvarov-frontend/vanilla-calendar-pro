# Анимация

Переходы между представлениями можно анимировать. Навигация по месяцам стрелками и листание списка годов едут по горизонтали, а открытие и закрытие выбора месяца и года идут кроссфейдом.

<Info>По умолчанию анимация выключена ради обратной совместимости: опция появилась позже, а её включение меняет то, что видит поиск по DOM во время перехода.</Info>

## Один тайминг на всё

Объект вместо `true` переопределяет тайминг. Значения верхнего уровня достаются всем переходам.

<Sandbox example="additional-features-animation-shared" height={400} />

## Раздельные тайминги

Два вида переходов можно настроить независимо. Вложите значения в `slide` для стрелок или в `fade` для пикеров — вложенные важнее заданных на верхнем уровне.

В примере ниже у слайда кривая с перелётом: месяц делает замах, проскакивает своё место и возвращается, а пикеры сохраняют спокойный кроссфейд.

<Info>Анимация не проигрывается, если посетитель запросил уменьшение движения через `prefers-reduced-motion: reduce`.</Info>

## Поиск по календарю во время анимации

Пока идёт переход, уходящее содержимое остаётся в DOM внутри слоя `[data-vc-ghost]` с атрибутом `inert`, поэтому элементы дат на это время присутствуют дважды. Колбэки вроде `onClickArrow` и `onClickDate` вызываются внутри этого окна, так что исключайте слой, если обходите календарь из них.

```ts
const dates = calendar.context.mainElement.querySelectorAll('[data-vc-date]');
const visible = [...dates].filter((date) => !date.closest('[data-vc-ghost]'));
```
