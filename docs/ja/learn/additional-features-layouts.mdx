# レイアウト

カレンダーでは、`layouts` パラメーターを使って HTML マークアップを手軽にカスタマイズできます。これにより、ボタンやその他の任意の HTML 要素など、独自の要素をカレンダーに追加できます。

`layouts` は、カレンダーの `type` をキー、文字列を値として受け取ります。

次の例では、`type: 'default'` のカレンダーヘッダーをカスタマイズし、カレンダー内に通常のボタンを追加しています。
