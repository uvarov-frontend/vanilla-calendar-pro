# スタイル

カレンダーで使われるすべての CSS クラスは変数になっており、独自の値に置き換えてカスタマイズできます。

<Info>CSS クラスを独自のものに置き換える場合は、そのクラスを自分の CSS で作成し、スタイルを定義する必要がある点に注意してください。</Info>

## CSS 変数

色だけを変更したい場合は、クラスを置き換える必要はまったくありません。組み込みテーマのすべての色は CSS カスタムプロパティとして公開されており、フォールバックにはテーマ本来の色が使われます。

```css
:root {
  --vc-date-selected-bg: #7c3aed;
  --vc-date-selected-color: #fff;
}
```

変数を明示的に設定しない限り、何も変わりません。変数の一覧は[リファレンスガイド](/ja/docs/reference/styles)にあります。

## モジュール式 CSS

既存の `styles/index.css`、`styles/layout.css`、`styles/themes/*.css` のインポートは、引き続き完全かつ互換性のある形で使えます。CSS を減らしたい場合は、使用するパーツを選んでください。JavaScript の拡張機能を登録しても、CSS は自動では読み込まれません。

任意の CSS パーツは[スタイルリファレンス](/ja/docs/reference/styles)で説明しています。既存のスタイルシート全体のインポートも引き続きサポートされており、例では必要なパーツのみを使用しています。
