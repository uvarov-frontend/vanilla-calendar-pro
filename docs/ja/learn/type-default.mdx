# デフォルト（単一）

## 静的

`'default'` タイプのカレンダーは 1 か月を表示し、日の選択、矢印による月の移動、各ヘッダーからの月と年の選択ができます。これはカレンダーの標準の表示モードです。

<Sandbox example="type-default" />

## Input 付き

**«Input»** をクリックしたときにカレンダーを表示したい場合は、`inputMode: true` パラメーターを指定して初期化するだけで簡単に設定できます。

<Info>
  このカレンダーにおける **«Input»** は、必ずしも `<input>` タグである必要はない点に注意してください。`<div>` など、任意の HTML 要素を使用できます。**«Input»** では、どの種類のカレンダーでも初期化できます。
</Info>

デフォルトでは、カレンダーは **«Input»** フィールドに値を書き込みません。そのため、`value` に何を表示するかを自由に制御できます。
