# 月リストでの月のクリックを処理する

すべての月のリストで月がクリックされたとき、このイベントを処理して、選択された要素とそのインデックスの情報を取得できます。

<Info>JS の標準に従い、月は 0 から番号が振られる点に注意してください。1 月が 0 番目、12 月が 11 番目の月に対応します。</Info>
