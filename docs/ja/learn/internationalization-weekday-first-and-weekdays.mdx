# 週の最初の曜日と週末

デフォルトでは、カレンダーはヨーロッパの標準である **ISO 8601** に基づいています。つまり、週の最初の曜日は月曜日です。

週の最初の曜日と表示する週末を定義する個別のパラメーターを使うと、任意の曜日を週の最初の曜日に指定したり、任意の曜日を週末に割り当てたりできます。空の配列を指定すれば、週末を完全に無効にすることもできます。
