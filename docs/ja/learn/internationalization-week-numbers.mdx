# 週番号

ESM への移行: 既存のオプションとコールバックはそのままにして、`vanilla-calendar-pro` から `weeks` をインポートし、呼び出さずにコンストラクターの `extensions: [weeks]` 配列に追加します。

国によっては、日付を表すのに週番号が使われます。
`enableWeekNumbers` パラメーターを `true` に設定すると、カレンダーに週番号を表示できます。
