# 曜日と週番号のクリックを処理する

ESM への移行: 既存のオプションとコールバックはそのまま使い、`vanilla-calendar-pro` から `weeks` をインポートして、呼び出さずにコンストラクターの `extensions: [weeks]` 配列に追加してください。

## 曜日

曜日のクリックを捕捉して、たとえばその曜日に該当する月内のすべての日を選択できます。

<Sandbox example="handle-click-on-weekday" />

## 週番号

`enableWeekNumbers` パラメーターを使ってカレンダーに週番号を表示し、そのクリックを処理できます。選択された週の日付の情報があれば、同じ方法でそれらの日付を簡単に選択できます。
