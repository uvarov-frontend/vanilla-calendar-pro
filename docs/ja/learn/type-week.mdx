# 週

`'week'` タイプのカレンダーは、1 か月全体ではなく 1 週間だけを表示します。予約フローや、選択内容に対して月のグリッドが場所を取りすぎる画面に適しています。

表示中の月に、選択された日付のうち最初のものが含まれる場合、ストリップはその日付を含む週で開きます。そうでない場合、今日がその月に含まれていれば今日を含む週を、それにも当てはまらなければ `selectedMonth` の最初の日を含む週を使用します。

<Sandbox example="type-week" height={300} />

矢印は 1 週間ずつ移動し、月の境界を越えてストリップを進めます。すべての日は現在の期間の日としてレンダリングされるため、表示月の外の日付としてグレーアウトされることはなく、クリックしてもストリップが移動することはありません。

<Info>
  2 つの月にまたがる週には、その週が属する月、つまり 4 日目を含む月のタイトルが付きます。これは ISO 週番号を決めるのと同じルールです。
</Info>

## 月を週に折りたたむ

`enableCollapse` を使うと、グリッドの下に月と週を切り替えるコントロールが追加され、ビューを開発者ではなく訪問者が選べるようになります。詳しくは [折りたたみ](/ja/docs/learn/additional-features-collapse) を参照してください。

同じコントロールは `inputMode` でも動作します。このポップアップは週として開き、`enableCollapse` で月全体に展開し、`enableSwipe` で現在のビューをページ送りします：

<Sandbox example="type-week-in-input" height={470} input={true} />

## プログラムによる切り替え

折りたたみは `type` を設定するため、2 つのビューは自分のコードからも切り替えられます：

```ts
calendar.set({ type: 'week' }); // fold down to a week
calendar.set({ type: 'default' }); // back to the month
calendar.type; // 'week' while collapsed
```

<Info>
  このタイプでは `displayMonthsCount` は `1` のままです。複数の週を並べて表示することはサポートされていません。複数のグリッドが必要な場合は `type: 'multiple'` を使用してください。
</Info>
