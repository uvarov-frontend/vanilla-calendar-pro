# 表示する日付範囲

`displayDateMin` と `displayDateMax` パラメーターは、カレンダーに表示できる日付の範囲を定義しますが、カレンダーのライフサイクルには影響しません。これらは、どの日付の表示と選択を許可するかを示すだけです。

たとえば、`displayDisabledDates` パラメーターが `true` に設定されている場合、ユーザーが閲覧できる最小年と最大年は、`dateMin` と `dateMax` パラメーターの値によって決まります。

<Sandbox example="date-management-display-range-dates" />

`displayDisabledDates` パラメーターを変更することで、カレンダーで閲覧・選択できる日付を制御できます。
