# 日のクリックを処理する

カレンダーでのユーザー操作に対応するため、さまざまなアクションが用意されており、そのひとつが `onClickDate()` です。このアクションを使うと、ユーザーがカレンダーの特定の日をクリックしたことを検知できます。

選択された日をコンソールに出力する例:

選択された日は配列として表される点に注意してください。カレンダーのパラメーターで許可されていれば、ユーザーは単一の日だけでなく日付範囲も選択できるためです。
