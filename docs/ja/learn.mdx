# Vanilla Calendar Pro の紹介

**Vanilla Calendar Pro** は、日付と時刻を扱うための強力で柔軟、かつ軽量なツールです。Web アプリケーションや Web サイト向けに、機能的で簡単にカスタマイズできるカレンダーを必要とする開発者のために作られました。外部ライブラリに依存せず高いパフォーマンスを備えているため、カレンダーが必要なあらゆるプロジェクトへの組み込みに最適です。

このカレンダーは、個人サイト、企業ポータル、複雑な Web アプリケーションなど、さまざまなプロジェクトに取り組む開発者向けに設計されています。Vanilla Calendar Pro は、日付をシンプルに表示したい場合にも、時刻の選択やインタラクティブなアクションといった高度な機能が必要な場合にも最適です。

## 主な機能

Vanilla Calendar Pro には豊富な機能が備わっており、使いやすく柔軟なカレンダーウィジェットを作成できます。

主な機能は次のとおりです。

- **軽量**: 最終的な JavaScript ファイルは minify され、高速に読み込めるよう最適化されています。
- **依存関係なし**: 完全にスタンドアロンで、追加のライブラリは必要ありません。
- **簡単なローカライズ**: あらゆる言語に簡単にローカライズできます。
- **カスタマイズ可能**: CSS と HTML マークアップで簡単に設定できます。
- **複数のインスタンス**: 1 つのページに無制限にカレンダーを配置できます。
- **テーマのサポート**: ライトテーマとダークテーマを自動で切り替え、カスタムテーマもサポートします。
- **週の開始日のカスタマイズ**: 任意の曜日を週の開始日として選択できます。
- **週末のカスタマイズ**: 週ごとに独自の週末を設定できます。
- **週番号の表示**: 1 年を通して週番号を表示できます。
- **`<input>` に縛られない**: 多くのカレンダーとは異なり、`<input>` 要素での使用に限定されません。
- **アクセシビリティ**: ARIA ラベル、`tabindex`、完全なキーボードナビゲーションを備え、アクセシビリティを高めます。
- **日付と時刻の範囲選択**: 最小値と最大値の制限付きで日付範囲と時刻範囲を選択できます。
- **ポップアップとツールチップ**: 独自の情報を表示するポップアップを設定でき、日付範囲の選択時にツールチップを追加できます。
