# ガイドの概要

このセクションでは、**Vanilla Calendar Pro API** の使い方を詳しく説明します。機能の紹介をお探しの場合は、[«学ぶ»](/ja/docs/learn) セクションをご覧ください。

Vanilla Calendar Pro API のドキュメントは、次の機能別サブセクションに分かれています。

1. **インスタンスの作成** — カレンダーのインスタンスをどこでどのように作成するか。
2. **ユーティリティ** — 日付をフォーマットするための関数。
3. **メソッド** — カレンダーのインスタンスを操作するために使えるメソッド。
4. **設定** — カレンダーの動作や表示を変更するために指定できるすべてのオプション。
5. **アクション** — カレンダーに対するさまざまな操作のデータを受け取り、処理できるイベントハンドラー。
6. **ポップアップ** — 任意の日を選び、その日にホバーしたときに簡単な情報をカレンダー上に直接表示できるポップアップ。
7. **レイアウト** — カレンダーの DOM 構造をほぼすべて変更し、独自の HTML 要素を追加できるテンプレート。
8. **スタイル** — カレンダーのスタイルを設定するための CSS クラスのオブジェクト。Tailwind CSS などの任意の CSS フレームワークや独自のクラスを使用できます。
9. **Aria-labels** — `aria-label` 用の文字列のオブジェクト。アクセシビリティを確保するため、カレンダーのすべてのラベルをローカライズできます。
