# スタイル

`styles` を使うと、カレンダー内のあらゆる CSS クラスを上書きできます。どの値も CSS クラスのリストに置き換えられます。

## モジュール化された CSS

既存の `styles/index.css`、`styles/layout.css`、`styles/themes/*.css` のインポートは、これまでどおりすべてのスタイルを含み、互換性も保たれています。CSS を削減したい場合は、使用するパーツだけを選んでください。JavaScript で拡張機能を登録しても、CSS は自動では読み込まれません。

各ファミリーには `core`、`motion`、`time`、`annotations`、`weeks`、`months` が用意されています。`core` と、有効にするすべての拡張機能（後から `set()` で有効にするオプションも含む）のスタイルをインポートしてください。

| パス | 内容 |
| --- | --- |
| `styles/index.css` | すべてのレイアウトルールと light/dark テーマ |
| `styles/{part}.css` | 選択したパーツ（レイアウトと light/dark テーマを含む） |
| `styles/layout/{part}.css` | 選択したレイアウトルールのみ（テーマなし） |
| `styles/themes/{theme}/{part}.css` | 1 つのテーマの選択したパーツのみ |

時刻選択があり、light/dark を自動で切り替えるカレンダーの場合:

```ts
import { Calendar, time } from 'vanilla-calendar-pro';
import 'vanilla-calendar-pro/styles/core.css';
import 'vanilla-calendar-pro/styles/time.css';

new Calendar('#calendar', {
  extensions: [time],
  selectionTimeMode: 24,
}).init();
```

テーマを 1 つだけ個別に選ぶ場合は、レイアウトのパーツと対応するテーマのパーツを使用します。たとえば、時刻選択がある light テーマのカレンダーの場合:

```ts
import { Calendar, time } from 'vanilla-calendar-pro';
import 'vanilla-calendar-pro/styles/layout/core.css';
import 'vanilla-calendar-pro/styles/layout/time.css';
import 'vanilla-calendar-pro/styles/themes/light/core.css';
import 'vanilla-calendar-pro/styles/themes/light/time.css';

new Calendar('#calendar', {
  extensions: [time],
  selectionTimeMode: 24,
  selectedTheme: 'light',
}).init();
```

別の組み込みテーマを使う場合は、`light` の代わりに `dark` または `slate-light` を指定します。カスタムテーマには、対応するレイアウトのパーツと独自の CSS だけが必要です。テーマの検出と `selectedTheme` はこれまでどおり動作します。カレンダーが切り替わる可能性のあるテーマはすべて読み込んでください。

同じルールを二重に読み込まないよう、レイヤーごとにフルファイルかモジュールファイルのどちらか一方を選んでください。CSS クラス、セレクター、ブラウザーサポート、公開されている `--vc-*` による上書きは変わりません。`motion` や `months` など一部のテーマパーツにはテーマ固有のルールがなく、空のスタイルシートとして有効です。

すべての拡張機能を使う場合は、フルのスタイルシートを使い続けてください。6 つのパーツをすべてインポートするよりも圧縮効率が高くなります。

ダウンロード用の `package.zip` には 5 つの完全なスタイルシートが含まれています。モジュール化された CSS は npm パッケージと CDN の直接 URL から利用できます。

## CSS クラス

以下はデフォルトのクラスの一覧です。

```ts
new Calendar('#calendar', {

    // Basics
    calendar: 'vc',

    column: 'vc-column',

    // Header
    header: 'vc-header',
    headerContent: 'vc-header__content',
    month: 'vc-month',

    arrowPrev: 'vc-arrow vc-arrow_prev',
    arrowNext: 'vc-arrow vc-arrow_next',

    // Month / year picker
    wrapper: 'vc-wrapper',
    content: 'vc-content',
    months: 'vc-months',
    monthsRow: 'vc-months__row',
    monthsCell: 'vc-months__cell',
    monthsMonth: 'vc-months__month',
    years: 'vc-years',
    yearsRow: 'vc-years__row',
    yearsCell: 'vc-years__cell',
    yearsYear: 'vc-years__year',

    // Week row / week numbers
    week: 'vc-week',
    weekDay: 'vc-week__day',
    weekDayBtn: 'vc-week__day-btn',
    weekNumbers: 'vc-week-numbers',
    weekNumbersTitle: 'vc-week-numbers__title',
    weekNumbersContent: 'vc-week-numbers__content',
    weekNumber: 'vc-week-number',

    // Dates
    collapse: 'vc-collapse',
    dates: 'vc-dates',
    datesRow: 'vc-dates__row',
    date: 'vc-date',
    dateBtn: 'vc-date__btn',
```

## CSS 変数

組み込みテーマ（`light`、`dark`、`slate-light`）のすべての色は、テーマ本来の色をフォールバックとする CSS カスタムプロパティで定義されています。そのため、CSS クラスに手を加えたり、テーマの上書きが正しくカスケードされるかを気にしたりすることなく、いくつかの変数を設定するだけでカレンダーの見た目を変更できます。

```css
:root {
  --vc-date-selected-bg: #7c3aed;
  --vc-date-selected-color: #fff;
}
```

変数を設定しない場合、カレンダーはこれまでとまったく同じように描画されます。変数を明示的に設定しない限り、何も変わりません。

<Info>`:root` に変数を設定すると、すべてのテーマに一度に適用されます（light/dark/slate-light はすべて同じ変数名を参照します）。1 つのテーマだけを変更したい場合は、`[data-vc-theme='dark'] { --vc-date-selected-bg: #7c3aed; }` のように、そのテーマのセレクターに上書きを限定してください。</Info>

## サイズ調整

カレンダーのサイズはすべて `rem` で指定されているため、ルートのフォントサイズに合わせて拡大縮小されます。ページがルートのフォントサイズをブラウザーのデフォルトである `16px` から変更している場合（Bootstrap 3 などの古いフレームワークでよく見られ、通常は `10px`）、カレンダーは正しくないスケールで表示されます。`transform` を 1 つ指定するだけで本来のサイズに戻せます:

```css
[data-vc='calendar'] {
  transform: scale(16 / <root font-size in px>);
}
```

たとえば、ルートが `10px` の場合は `transform: scale(1.6);` とします。
