# レイアウト

この API は HTML を受け付けます。信頼できるマークアップを使用するか、ユーザーなど信頼できないソースから来るコンテンツの場合は [`sanitizerHTML`](/ja/docs/reference/settings#sanitizerhtml) を設定してください。デフォルトのコールバックはサニタイズを行いません。

`<#ControlTime />` には `time` と有効な `selectionTimeMode` が必要です。`<#Collapse />` には `weeks` と `enableCollapse: true` が、`<#WeekNumbers />` には `weeks` と `enableWeekNumbers: true` が必要です。`<#DateRangeTooltip />` には `annotations` と `onCreateDateRangeTooltip` が必要です。`<#Multiple>` には `months` が必要です。テンプレートのタグと既存のオプションはそのまま残してください。

レイアウトを使うと、カレンダーの DOM 構造をほぼ完全に変更し、ボタンなどの独自の HTML 要素を追加できます。カレンダーの種類ごとにデフォルトのテンプレートがあり、それぞれをカスタマイズできます。

<Info>
  記号 **«#»** を含むタグはカレンダーに登録済みのコンポーネントで、タグの末尾に閉じスラッシュが必要です。ただし、1 か月分をラップするタグ **\<#Multiple>\<#/Multiple>** は例外です。
  各デフォルトテンプレートには、そのテンプレートで使用可能なすべてのコンポーネントが記載されています。
</Info>

## layouts.default

`Type: String`

`Default: string`

`Options: string`

```ts
new Calendar('#calendar', {
  layouts: {
    default: `
      <div class="${self.styles.header}" data-vc="header" role="group" aria-label="${self.labels.navigation}">
        <#ArrowPrev [month] />
        <div class="${self.styles.headerContent}" data-vc-header="content" aria-live="polite" aria-atomic="true">
          <#Month />
          <#Year />
        </div>
        <#ArrowNext [month] />
      </div>
      <div class="${self.styles.wrapper}" data-vc="wrapper">
        <#WeekNumbers />
        <div class="${self.styles.content}" data-vc="content" role="grid">
          <#Week />
          <#Dates />
          <#DateRangeTooltip />
        </div>
      </div>
      <#Collapse />
      <#ControlTime />
    `,
  },
});
```

1 か月とその日付を表示するためのデフォルトテンプレートです。

## layouts.multiple

`Type: String`

`Default: string`

`Options: string`

```ts
new Calendar('#calendar', {
  layouts: {
    multiple: `
      <div class="${self.styles.controls}" data-vc="controls" role="group" aria-label="${self.labels.navigation}">
        <#ArrowPrev [month] />
        <#ArrowNext [month] />
      </div>
      <div class="${self.styles.grid}" data-vc="grid">
        <#Multiple>
          <div class="${self.styles.column}" data-vc="column" role="group">
            <div class="${self.styles.header}" data-vc="header">
              <div class="${self.styles.headerContent}" data-vc-header="content" aria-live="polite" aria-atomic="true">
                <#Month />
                <#Year />
              </div>
            </div>
            <div class="${self.styles.wrapper}" data-vc="wrapper">
              <#WeekNumbers />
              <div class="${self.styles.content}" data-vc="content">
                <#Week />
                <#Dates />
              </div>
            </div>
          </div>
        <#/Multiple>
        <#DateRangeTooltip />
      </div>
      <#ControlTime />
    `,
  },
});
```

複数の月とその日付を表示するためのデフォルトテンプレートです。
