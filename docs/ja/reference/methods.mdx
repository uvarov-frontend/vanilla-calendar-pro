# メソッド

拡張機能はインスタンスの作成時に確定します。後から `set()` や `update()` で有効にする機能のモジュールも、あらかじめ登録しておいてください。これらのメソッドは既存の機能オプションを変更することはできますが、モジュールを追加・削除することはできません。同じオプションや拡張機能の配列を使い回すことはサポートされており、各カレンダーはそれぞれ独立した状態を持ちます。対応する拡張機能なしで機能を有効にすると、`init()`、`set()`、`update()` の実行時に内容を説明するエラーがスローされます。有効になっていない設定やコールバックにはモジュールは不要です。

## init()

`init()` メソッドは、カレンダーの初期化処理を開始する主要なインスタンスメソッドです。

```ts
const calendar = new Calendar(element, params);
calendar.init();
```

## update()

`update()` メソッドを使うと、カレンダーに新しい設定を適用してリセットできます。
このメソッドはリセットを制御するための任意の引数を持つオブジェクトを受け取ります。デフォルトでは、更新後にユーザーが選択した日付、月、年がリセットされます。

すべての引数のデフォルト値は `true` です。

```ts
{
  year: boolean;
  month: boolean;
  dates: boolean | 'only-first';
  holidays: boolean;
  time: boolean;
}
```

- `true` - 設定で指定したパラメーターにリセットします。
- `false` - リセットせず、ユーザーが選択したパラメーターをそのまま残します。
- `'only-first'` - 選択されたすべての日付をリセットし、最も早い日付だけを残します。日付の選択タイプが `'multiple-ranged'` に指定されている場合は、ホバー用に `'mousemove'` と `'keydown'` のハンドラーが追加されます。

使用例:

```ts
calendar.locale = 'de-AT';
calendar.firstWeekday = 0;

calendar.update({
  dates: true,
});
```

## set()

未初期化または初期化済みのカレンダーに新しいパラメーターやハンドラーを指定する必要がある場合は、`.set()` メソッドを使用できます。
このメソッドは、新しいパラメーターを持つオブジェクトと、リセットを制御するための任意の引数を持つオブジェクトを受け取ります。デフォルトでは、更新後にユーザーが選択した日付、月、年がリセットされます。

使用例:

```ts
calendar.set({
  locale: 'de-AT',
  firstWeekday: 0,
}, {
  dates: true,
});
```

このメソッドは、カレンダーのインスタンス作成時にパラメーターを指定する方法の代わりとしても使えます。初期化前にこのメソッドを呼び出す場合は、リセットを制御するオブジェクトを指定しないでください。

```ts
const calendar = new Calendar(element);
calendar.set({ locale: 'de-AT', firstWeekday: 0 });
calendar.init();
```

---

## destroy()

カレンダーのインスタンスを完全に削除する必要がある場合は、`destroy()` メソッドを使用できます。

```ts
calendar.destroy();
```

---

## show()

`show()` メソッドを使うと、非表示になっているカレンダーを表示できます。

```ts
calendar.show();
```

---

## hide()

`hide()` メソッドを使うと、表示されているカレンダーを非表示にできます。

```ts
calendar.hide();
```
