# 주 번호

ESM 마이그레이션: 기존 옵션과 콜백을 유지하고 `vanilla-calendar-pro`에서 `weeks` 확장을 import한 뒤 생성자의 `extensions: [weeks]` 배열에 추가하세요. 함수처럼 호출하지 않습니다.

일부 국가에서는 날짜 표시에 주 번호를 사용합니다.
`enableWeekNumbers` 파라미터를 `true`로 설정하면 캘린더에 주 번호를 표시할 수 있습니다.
