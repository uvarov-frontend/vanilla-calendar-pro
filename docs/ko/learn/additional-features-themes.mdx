# 테마

캘린더는 커스텀 테마를 지원하며 기본으로 라이트/다크 테마를 제공합니다.

`themeAttrDetect` 파라미터가 `false`로 설정되면, 테마는 사용자의 시스템 설정 또는 `selectedTheme` 파라미터로 결정됩니다.

캘린더는 지정된 태그와 속성을 기준으로 사이트의 테마를 자동 감지하고 추적할 수 있습니다. 이 파라미터에 대한 자세한 내용은 레퍼런스 가이드에서 확인할 수 있습니다.

사이트가 하나의 테마만 지원하거나 캘린더의 외형을 원하는 대로 커스터마이징하려면, 제공되는 테마 중 하나를 명시적으로 선택할 수 있습니다.

아래 예제는 다크 테마를 강제로 사용하는 방법을 보여줍니다:

<Sandbox example="additional-features-themes-dark" themeDetection={false} />

아래는 동일한 예제이지만 라이트 테마를 사용합니다:

<Sandbox example="additional-features-themes-light" themeDetection={false} />

위에서 설명한 것처럼, 직접 만든 테마를 사용하거나 캘린더에 존재하는 테마를 가져와 사용할 수 있습니다.

## 모듈별 CSS

기존 `styles/index.css`, `styles/layout.css`, `styles/themes/*.css`는 모든 기능의 스타일을 계속 제공하며 호환성을 유지합니다. CSS 크기를 줄이려면 필요한 부분만 가져오세요. JavaScript 확장을 등록해도 CSS가 자동으로 로드되지는 않습니다.

```ts
import { Calendar, time } from 'vanilla-calendar-pro';
import 'vanilla-calendar-pro/styles/layout/core.css';
import 'vanilla-calendar-pro/styles/layout/time.css';
import 'vanilla-calendar-pro/styles/themes/light/core.css';
import 'vanilla-calendar-pro/styles/themes/light/time.css';

new Calendar('#calendar', {
  extensions: [time],
  selectionTimeMode: 24,
  selectedTheme: 'light',
}).init();
```

`light` 대신 `dark` 또는 `slate-light`를 사용할 수 있습니다. 사용자 정의 테마에는 해당 레이아웃 부분과 직접 작성한 CSS만 필요합니다. 테마 감지와 `selectedTheme`는 기존과 동일하게 동작합니다. 달력이 전환할 수 있는 모든 테마를 가져오세요.

선택적 CSS 가져오기는 [스타일 참조](/docs/reference/styles)에 설명되어 있습니다. 기존 전체 스타일시트도 지원되며, 예제는 필요한 부분만 가져옵니다.
