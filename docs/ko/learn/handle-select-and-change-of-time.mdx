# 시간 선택 및 변경 처리

확장 기능이 없는 이전 버전에서 업그레이드할 때 기존 옵션과 콜백은 유지하세요. ESM에서는 `timePicker`을 이름으로 import하고 생성자에 `extensions: [timePicker]`을 추가하세요. 확장 기능을 함수처럼 호출하지 않습니다. import하거나 등록하는 것만으로 기능이 활성화되지는 않습니다.

```ts
import { Calendar, timePicker } from 'vanilla-calendar-pro';

new Calendar('#calendar', {
  extensions: [timePicker],
  selectionTimeMode: 24,
}).init();
```

`selectionTimeMode` 파라미터를 활성화하면 시간 변경 시마다 필요한 데이터를 자동으로 받을 수 있습니다.
