# Week Numbers

ESM migration: keep the existing options and callbacks, import `weeks` from `vanilla-calendar-pro`, and add it to the constructor’s `extensions: [weeks]` array without calling it.

In some countries, week numbers are used to denote dates.
You can enable the display of week numbers in the calendar by setting the `enableWeekNumbers` parameter to `true`.
